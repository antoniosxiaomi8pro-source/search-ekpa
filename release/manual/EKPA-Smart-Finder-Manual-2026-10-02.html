1. Επισκόπηση

elearningekpa.gr → GTM Smart Finder Widget → HTTPS → smartfinder backend → Search Engine → αποτελέσματα

Το Smart Finder είναι ανεξάρτητο από τον κώδικα του Symfony/PHP site. Το widget εισάγεται μέσω Google Tag Manager και καλεί το backend μέσω HTTPS. Η αναζήτηση γίνεται στον Node.js/Express server, που κρατά στη μνήμη τον κατάλογο, το taxonomy και το λεξικό. Δεν υπάρχει βάση δεδομένων: όλα τα δεδομένα είναι αρχεία JSON στον φάκελο DATA_DIR.

2. Front-end: χρήση από επισκέπτη

Ο επισκέπτης πληκτρολογεί κανονικά στο search box. Το widget ζητά live αποτελέσματα και τα εμφανίζει σε dropdown. Με Enter ή με το εικονίδιο της αναζήτησης ανοίγει η σελίδα /search?q=… της ίδιας της ιστοσελίδας, όπου το Smart Finder εμφανίζει τη λίστα αποτελεσμάτων.

Search boxes που υποστηρίζει το widget

SelectorΘέση
#qHeroFrontΑρχική σελίδα
#qNavHeader desktop
#qNavMobileHeader mobile
#qAsideΣελίδα κατηγορίας
#qSearchΣελίδα αποτελεσμάτων /search

Dropdown προτάσεων

  • Εμφανίζεται από 2 χαρακτήρες και πάνω, με μικρή καθυστέρηση (περίπου 0,2 δευτ.) ώστε να μη στέλνεται αίτημα σε κάθε πλήκτρο.
  • Δείχνει έως 6 προγράμματα, με εικόνα και τίτλο. Οι τίτλοι τυλίγονται σε πολλές γραμμές.
  • Mouse-over και πλήκτρα βελών δίνουν highlight. Το κλικ ανοίγει το πρόγραμμα.

Σελίδα αποτελεσμάτων (/search?q=…)

  • Τίτλος «Αποτελέσματα αναζήτησης», πλήθος αποτελεσμάτων και ταξινόμηση Σχετικότητα ή Τιμή (χαμηλότερη προς υψηλότερη).
  • Κάθε αποτέλεσμα είναι κάρτα: εικόνα (περίπου 38% της γραμμής, σχήμα 16:9, πάνω από την περιγραφή σε κινητό), τίτλος, περιγραφή έως 5 γραμμές, Κατευθύνσεις και Σχετικά Προγράμματα.
  • Κατευθύνσεις: όλες οι κατηγορίες του προγράμματος ως links προς τις επίσημες σελίδες κατηγορίας του site. Κατηγορία που δεν υπάρχει στο site δεν γίνεται link.
  • Σχετικά Προγράμματα: έως 8, ως links.
  • 40 αποτελέσματα ανά σελίδα, με κουμπί «Εμφάνιση περισσότερων».
  • Δεν εμφανίζονται προγράμματα που δεν δέχονται αιτήσεις (π.χ. έληξε η προθεσμία τους). Επανεμφανίζονται όταν ανοίξουν ξανά.
  • Οι τιμές δεν εμφανίζονται στις κάρτες (εκκρεμεί απόφαση για την τιμή που δείχνουμε). Η ταξινόμηση ανά τιμή χρησιμοποιεί την τρέχουσα τιμή κύκλου.

Τι «καταλαβαίνει» η αναζήτηση

  • Ελληνικά με ή χωρίς τόνους, πεζά/κεφαλαία, και Greeklish (π.χ. «psixologia»).
  • Μικρά ορθογραφικά λάθη (π.χ. «ψυχολοια» βρίσκει «Ψυχολογία»).
  • Συνώνυμα και συγγενείς όροι μέσω του taxonomy (π.χ. «ΑΙ», «τεχνητή νοημοσύνη»).
  • Ονόματα κατηγοριών και λέξεις του λεξικού (π.χ. «ναυτικός» → Ναυτιλιακά, «δάσκαλος» → Παιδαγωγικά).
Προαιρετικό block στο <head> του site. Ένα tag του GTM τρέχει πάντα λίγο μετά την εμφάνιση της σελίδας. Για να μη φαίνεται για κλάσμα του δευτερολέπτου η λίστα του ίδιου του site στο /search, υπάρχει το αρχείο SITE-HEAD-HOLD-2026-10-01.html (δύο μικρά blocks, χωρίς εξωτερικούς πόρους). Μπαίνει στο <head> όλων των σελίδων, πάνω από το snippet του GTM. Αν το GTM δεν φορτώσει, η λίστα του site επανέρχεται μόνη της σε 3 δευτερόλεπτα. Διαγράφεται με σβήσιμο των δύο blocks.

3. GTM — διαχείριση του widget

IT Το widget διαχειρίζεται ανεξάρτητα από το Symfony, ως Custom HTML tag στο GTM container GTM-TZJNFCW.

Αρχείο testing…-VALIDATED.txt (δείχνει στο Railway, μόνο για το tag SmartFinder - TESTING2)
Backend URLΕίναι γραμμένο μέσα στο αρχείο (γραμμή var BACKEND_URL = "…"). Δεν χρησιμοποιείται GTM variable, γιατί ο editor του GTM απορρίπτει το tag όταν περιέχει αναφορά σε variable.
ΓλώσσαES5. Το GTM δεν δέχεται νεότερη σύνταξη (let, const, arrow functions, template literals).
TriggerΠροτείνεται «Initialization - All Pages» (η νωρίτερη στιγμή που τρέχει tag στο GTM).

Σειρά: πρώτα εγκαθίσταται και επαληθεύεται ο backend, και μόνο μετά δημοσιεύεται το production tag. Το tag SmartFinder - TESTING2 δεν τροποποιείται, δεν μετονομάζεται και δεν δημοσιεύεται.

Πριν από Publish

  1. Preview/Tag Assistant και έλεγχος ότι το tag κάνει fire στις σωστές σελίδες.
  2. Network check: το /api/search απαντά HTTP 200.
  3. Έλεγχος σε /search?q=ναυτιλία: κάρτες, κατηγορίες που ανοίγουν, κανένα κενό πάνω από τα αποτελέσματα, δεν φαίνεται η λίστα του site.
  4. Έλεγχος Pending Changes ώστε να μην περιλαμβάνονται άσχετες αλλαγές.
  5. Δεύτερος έλεγχος από μέλος του IT όταν το GTM container είναι κοινό με production.

4. Search API

EndpointΧρήση
GET /healthHealth check: {"ok":true,"programs":702,"active_programs":693}. Το programs είναι ο συνολικός κατάλογος, το active_programs όσα βλέπουν οι επισκέπτες.
GET /api/search?q=…&limit=6&fields=compactΠροτάσεις για το dropdown.
GET /api/search?q=…&format=paged&page=1&page_size=40&sort=relevance|price_ascΣελίδα αποτελεσμάτων: {results, pagination}.
GET /api/programsΟ κατάλογος που βλέπουν οι επισκέπτες (μόνο ενεργά), με category_links. Ο browser το επανελέγχει σε κάθε επίσκεψη (ETag), ώστε να μη μένει παλιά έκδοση.
GET /concepts.json, GET /lexicon.jsonΤο ισχύον taxonomy και λεξικό.
POST /api/track-search, POST /api/track-clickBackend analytics.
POST /api/chatΠροαιρετικός AI βοηθός (server-side proxy). Δεν επηρεάζει την αναζήτηση.

Η μηχανή αναζήτησης είναι το public/search-engine.js, ο ίδιος κώδικας για τον server και τη σελίδα δοκιμών. Είναι προστατευμένος: αλλάζει μόνο με πλήρη έλεγχο ότι τα αποτελέσματα μένουν ίδια (regression tests σε ελεγμένες αναζητήσεις). Τα δεδομένα που αλλάζει το ΕΚΠΑ (κατάλογος, taxonomy, λεξικό) δίνονται στη μηχανή ως είσοδος και δεν χρειάζονται αλλαγή του κώδικα.

Οι απαντήσεις έχουν Vary: Origin και το CORS επιτρέπει μόνο τα origins του ALLOWED_ORIGINS.

5. Admin — γενικά

  2. Εισαγωγή του ADMIN_TOKEN και «Ξεκλείδωμα».
  3. Επιλογή καρτέλας.

Δικαιώματα: σήμερα υπάρχει ένα κοινό ADMIN_TOKEN. Το μοντέλο δικαιωμάτων (ένα token ανά ρόλο, λογαριασμοί ή login ΕΚΠΑ) θα οριστεί με το IT.

  1. Φόρτωση του τρέχοντος taxonomy.
  2. Προσθήκη/αφαίρεση concepts και όρων.
  3. Save.

  • Υπάρχει έλεγχος στον server πριν την αποθήκευση και προειδοποίηση όταν η αλλαγή αλλάζει ήδη ελεγμένες αναζητήσεις.
  • Όρια: 10 αιτήματα/λεπτό ανά IP στα admin endpoints.

7. Admin: Κατάλογος προγραμμάτων

ΕΚΠΑ Η καρτέλα 📚 Κατάλογος ενημερώνει τον κατάλογο από το elearningekpa.gr. Αναλυτικός οδηγός: ADMIN-CATALOG-GUIDE.md.

Τι κάνει ο έλεγχος

  • Κρύβει τα προγράμματα που δεν δέχονται αιτήσεις (δεν υπάρχουν στον «Τρέχοντα Κύκλο» ή η σελίδα τους γράφει «Το πρόγραμμα δεν είναι διαθέσιμο»). Δεν διαγράφονται: μένουν στο αρχείο και ξαναεμφανίζονται όταν ανοίξουν.
  • Προσθέτει τα νέα προγράμματα του κύκλου, πλήρη (id, κατηγορία, περιγραφή, έννοιες, σχετικά).
  • Ενημερώνει τις τιμές (η τιμή του κύκλου, με την έκπτωση που ισχύει) και κρατά τη βασική τιμή χωριστά.
  • Συμπληρώνει κενά σε υπάρχοντα προγράμματα, αλλά ποτέ δεν αλλάζει πεδίο που έχει ήδη τιμή.

Πώς γίνεται

  1. Πάτα 🔍 Έλεγχος καταλόγου. Διαρκεί περίπου 25 λεπτά και τρέχει στον server. Μπορείς να κλείσεις τη σελίδα και να γυρίσεις αργότερα.
  2. Δες το αποτέλεσμα: λίστα αλλαγών και αλλαγές στα αποτελέσματα αναζήτησης για ελεγμένες αναζητήσεις, κατηγορίες και έννοιες.
  3. Πάτα Εφαρμογή αν συμφωνείς. Πριν κάθε εφαρμογή κρατιέται αυτόματα backup.
  4. Αν χρειαστεί: Επαναφορά της προηγούμενης έκδοσης με ένα κλικ.

Το ⚡ γρήγορο κουμπί ελέγχει σε λίγα δευτερόλεπτα μόνο ποια προγράμματα είναι ενεργά (όχι τιμές, όχι νέα). Η καρτέλα εμφανίζει υπενθύμιση όταν ο «Τρέχων Κύκλος» του site έχει αλλαγές.

Δικλείδες ασφαλείας

  • Αν η λίστα του κύκλου είναι λιγότερη από το 50% του καταλόγου, ή θα κρυφτεί πάνω από το 15% των προγραμμάτων, ή θα αλλάξουν πάνω από 30% των τιμών, η Εφαρμογή κλειδώνει (ύποπτο αποτέλεσμα, π.χ. το site δεν είχε ενημερωθεί).
  • Η λίστα του site διαβάζεται αργά, μία σελίδα ανά 2 δευτερόλεπτα, για να μην επιβαρύνεται το site.

Δύο δρόμοι για τον κατάλογο: ο νεότερος έλεγχος υπερισχύει

Το πακέτο φέρνει έναν ελεγμένο κατάλογο και το ΕΚΠΑ μπορεί να πατά το κουμπί. Ο server χρησιμοποιεί όποιον έχει νεότερη ημερομηνία ελέγχου. Αν κερδίσει ο κατάλογος ενός νέου πακέτου, ο κατάλογος του DATA_DIR κρατιέται πρώτα ως backup. Η καρτέλα δείχνει πάντα ποιος ισχύει (πακέτο, κουμπί ή επαναφορά) και με ποια ημερομηνία.

Μελλοντική πηγή: όταν το IT δώσει feed ή endpoint του καταλόγου, το κουμπί μένει ίδιο και αλλάζει μόνο η πηγή.

8. Admin: Λεξικό

ΕΚΠΑ Το λεξικό λέει στην αναζήτηση πώς να καταλαβαίνει λέξεις όπως «δάσκαλος», «ναυτικός» ή «σεφ». Αλλάζει από την καρτέλα 📖 Λεξικό, χωρίς developer και χωρίς νέο πακέτο. Αναλυτικός οδηγός: ADMIN-LEXICON-GUIDE.md.

ΕνότηταΤι κάνειΠαράδειγμα
🚫 Λέξεις που αγνοούνταιΛέξεις χωρίς νόημα για την αναζήτησηκαι, για, πρόγραμμα
🏷️ Λέξη → κατηγορίαΗ λέξη δείχνει όλη την κατηγορία. Ισχύει και μέσα σε φράση.«ναυτικός» → Ναυτιλιακά
👥 Κοινό / επάγγελμαΙσχύει όταν ο επισκέπτης γράφει μόνο τη λέξη. Δείχνει κατηγορίες ή συγκεκριμένα προγράμματα.«δάσκαλος» → Παιδαγωγικά και Μοριοδοτούμενα

Γράφονται κανονικά ελληνικά. Οι τόνοι και τα κεφαλαία καλύπτονται αυτόματα. Οι κλίσεις δεν καλύπτονται: γράψε χωριστά ενικό, πληθυντικό και γενική (π.χ. δάσκαλος, δασκάλου, δασκάλων).

Πώς αλλάζεις το λεξικό

  1. Κάνε τις αλλαγές στις ενότητες.
  2. Πάτα 🔍 Προεπισκόπηση αλλαγών. Δείχνει τι αλλάζει στα αποτελέσματα, χωρίς να αγγίζει τους επισκέπτες.
  3. Διάβασε την προεπισκόπηση και τις προειδοποιήσεις.
  4. Πάτα 💾 Αποθήκευση και επιβεβαίωσε. Ισχύει αμέσως.
  5. Αν χρειαστεί: ⏪ Επαναφορά προηγούμενης έκδοσης.

Τι δείχνει η προεπισκόπηση

  • Πώς αλλάζει η αναζήτηση για τις λέξεις που άλλαξες (αναμενόμενο).
  • Ποιες άλλες αναζητήσεις αλλάζουν (ελεγμένες, κατηγορίες, έννοιες). Εκεί χρειάζεται έλεγχος.
  • Για κάθε αναζήτηση, κάθε αλλαγή στα 3 πρώτα αποτελέσματα: πρόγραμμα που μπαίνει, ανεβαίνει, φεύγει ή αλλάζει θέση.

Προειδοποιήσεις και σφάλματα

ΜήνυμαΣημασία
Η λέξη ταιριάζει ήδη με την κατηγορία «…»Η αναζήτηση τη βλέπει ως κατηγορία πριν φτάσει στον κανόνα σου, άρα ο κανόνας δεν θα ισχύσει. Εμφανίζεται ζωντανά, ενώ γράφεις.
Η ομάδα έχει λέξεις αλλά κανένα πρόγραμμα/κατηγορίαΣφάλμα: δεν αποθηκεύεται.
Το πρόγραμμα είναι κρυμμένο ή δεν υπάρχει πιαΔεν θα εμφανίζεται. Αφαίρεσέ το ή περίμενε να ανοίξει.
Η κατηγορία δεν υπάρχει στον κατάλογοΣφάλμα: δεν αποθηκεύεται.

Ασφάλεια του λεξικού

  • Πριν κάθε αποθήκευση κρατιέται backup (τα 20 τελευταία).
  • Αν αποθηκεύσει κάποιος άλλος στο μεταξύ, η αποθήκευσή σου απορρίπτεται, ώστε να μη χαθεί η δική του αλλαγή.
  • Ένα νέο πακέτο δεν αντικαθιστά ποτέ το λεξικό του ΕΚΠΑ. Το λεξικό του πακέτου αντιγράφεται στο DATA_DIR μόνο αν δεν υπάρχει.
  • Αν το αρχείο του λεξικού χαλάσει, ο server δεν σταματά: χρησιμοποιεί το ενσωματωμένο λεξικό και δείχνει το πρόβλημα στην καρτέλα.

9. Analytics και παρακολούθηση

Υπάρχουν δύο επίπεδα, που συμπληρώνουν το ένα το άλλο.

A. GA4 (πηγή δεδομένων χρήσης)
Events από τον browser: search (όρος αναζήτησης), select_content (επιλογή προγράμματος από το dropdown) και search_no_results. Δίνει χρονική διάσταση (ανά κύκλο) και τι κάνει ο επισκέπτης στο site. Απαιτεί ρύθμιση: custom dimensions search_term, item_id, content_id, content_type και διατήρηση δεδομένων 14 μηνών. Βήμα-βήμα οδηγός ρύθμισης: MANUAL-GA4-Smart-Finder.md (από τον Antonis Papachrisanthou). Τα custom dimensions δεν δουλεύουν αναδρομικά: ρυθμίζονται πριν ανοίξει το production tag.
B. Backend analytics (καρτέλα Analytics)
Aggregate στοιχεία ανά ερώτημα: πόσες φορές αναζητήθηκε, πόσες δεν βρήκε αποτέλεσμα, ποια προγράμματα πατήθηκαν. Κρατά έως 2000 διαφορετικά ερωτήματα και δεν έχει ημερομηνίες. Είναι μόνο για προβολή: δεν επηρεάζει το ranking.
Γνωστό κενό: τα κλικ στις κάρτες της σελίδας αποτελεσμάτων δεν καταγράφονται σε κανένα από τα δύο επίπεδα (καταγράφεται μόνο η επιλογή από το dropdown).

Testing: τα δεδομένα του testing πρέπει να μένουν χωριστά από τα production analytics.

11. Ασφάλεια

  • Το LLM API key δεν εκτίθεται στον browser: το /api/chat λειτουργεί ως server-side proxy.
  • Το ADMIN_TOKEN διανέμεται μόνο σε όσους χρειάζονται. Αν λείπει, το admin είναι fail-closed.
  • Το CORS επιτρέπει μόνο τα απαιτούμενα origins.
  • Τα secrets ανήκουν σε environment variables και όχι σε Git, GTM ή frontend.
  • Όλα τα admin endpoints χρειάζονται token και έχουν rate limiting. Το μεγαλύτερο όριο μεγέθους σώματος ισχύει μόνο μετά τον έλεγχο του token.
  • Τα πακέτα δεν περιέχουν ποτέ .env, analytics ή runtime δεδομένα. Το script κατασκευής τα αποκλείει.

12. Εκδόσεις και παράδοση πακέτων

Antonis Papachrisanthou Κάθε αλλαγή κώδικα παραδίδεται ως νέο πακέτο με ημερομηνία (π.χ. ekpa-smart-finder-IT-package-2026-10-02-PRODUCTION.zip). Δεύτερο πακέτο της ίδιας ημέρας παίρνει -v2. Ένα πακέτο που έχει σταλεί δεν αλλάζει ποτέ.

Τι περιέχει ένα πακέτο

  • Φάκελος search-ekpa/ (backend και δεδομένα εκκίνησης).
  • Το production widget του GTM και, προαιρετικά, το block για το <head>.
  • Οι οδηγοί και το addendum της ημερομηνίας του πακέτου (αυτό υπερισχύει όπου υπάρχει διαφορά με παλιότερα έγγραφα).
  • Το RELEASE-MANIFEST με SHA-256 των βασικών αρχείων.

Πώς φτιάχνεται

Με script, όχι με το χέρι: ο κώδικας βγαίνει από ένα συγκεκριμένο commit του git, τρέχουν όλα τα tests, ξεκινά πραγματικός server από το πακέτο και ελέγχονται το API του widget, το CORS, ο κατάλογος, το λεξικό και το admin. Το πακέτο δεν φτιάχνεται αν κάποιος έλεγχος αποτύχει ή αν λείπει το addendum.

Εγκατάσταση (σύνοψη)

  1. Backend πρώτα: deploy του search-ekpa/, npm ci, DATA_DIR, ADMIN_TOKEN, restart.
  2. Επαλήθευση με τις εντολές του addendum. Όλες πρέπει να περνούν.
  3. Μόνο μετά, δημοσίευση του tag του GTM.
  4. (Προαιρετικά) πρόσθεση του block στο <head>.

Rollback: κράτησε την προηγούμενη εγκατάσταση του backend (ή το commit της) και το προηγούμενο περιεχόμενο του tag. Το block του <head> αφαιρείται με σβήσιμο.

  • Απόφαση για feed καταλόγου από το IT (προαιρετικά, σε επόμενο βήμα).
