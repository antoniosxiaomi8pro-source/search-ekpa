GA4: μίνι εγχειρίδιο

Τι στέλνει το widget, τι πρέπει να ρυθμιστεί, ποιες αναφορές βγαίνουν. Για όσους ξέρουν GA4.

Property: Elearning - GA4 · G-ZL8304SEHG · GTM GTM-TZJNFCW · Widget: v30 · Έκδοση εγγράφου: 02/10/2026

Προτεραιότητα: ρύθμισε τα custom dimensions και τη διατήρηση πριν δημοσιευτεί το production tag. Οι custom dimensions δεν εφαρμόζονται αναδρομικά στις αναφορές, και τα Explorations φτάνουν μόνο όσο η διατήρηση επιτρέπει.

1. Τι στέλνει το widget

EventΠότεΠαράμετροι
searchΑναζήτηση ≥ 2 χαρακτήρων. Στέλνεται με debounce 600 ms ή στο submit, και δεν επαναλαμβάνεται για τον ίδιο όρο στη σειρά.search_term
search_no_resultsΤο dropdown δεν βρήκε προγράμματα. Δεν επαναλαμβάνεται για τον ίδιο όρο στη σειρά. Δεν στέλνεται όταν απέτυχε το δίκτυο.search_term
select_contentΕπιλογή προγράμματος από το dropdown (κλικ ή Enter σε επιλεγμένη πρόταση).search_term, item_id (slug), content_id (τίτλος), content_type = course
  • Αποστολή με gtag('event', …, {send_to: 'G-ZL8304SEHG'}). Αν δεν υπάρχει gtag() στη σελίδα, το widget κάνει dataLayer.push με event ekpa_search, ekpa_search_no_results, ekpa_select_content. Τότε χρειάζεται GA4 Event tag στο GTM που τα προωθεί.
  • Δεν στέλνονται personal data. Το search_term είναι το κείμενο που πληκτρολόγησε ο χρήστης.
Κενό: τα κλικ στις κάρτες της σελίδας αποτελεσμάτων (/search?q=…) δεν στέλνουν event. Η μέτρηση της επιλογής προγράμματος καλύπτει μόνο το dropdown.

2. Ρύθμιση (μία φορά, ~15 λεπτά)

Απαιτούμενος ρόλος: Editor ή Administrator στο property.

Admin → Data display → Custom definitions → Create custom dimension (scope Event):

Dimension nameEvent parameterΠεριεχόμενο
SF Search termsearch_termΌρος αναζήτησης
SF Program slugitem_idSlug προγράμματος
SF Program titlecontent_idΤίτλος προγράμματος
SF Content typecontent_typeΤύπος (course)
  • Η παράμετρος γράφεται ακριβώς όπως φαίνεται (πεζά, underscore).
  • Αν το GA4 αρνηθεί το search_term (δεσμευμένο ή υπάρχει ήδη), χρησιμοποίησε την ενσωματωμένη διάσταση Search term και συνέχισε με τις υπόλοιπες. Αν υπάρχει ήδη διάσταση για κάποια παράμετρο με άλλο όνομα, μην φτιάξεις δεύτερη: κράτησε το όνομά της.
  • Admin → Data collection and modification → Data retention: Event data retention = 14 months (προεπιλογή: 2 μήνες).
  • Οι νέες διαστάσεις εμφανίζονται στις αναφορές σε 24–48 ώρες.

3. Έλεγχος

  1. Realtime / DebugView: κάνε στο site 2–3 αναζητήσεις (μία με σκοπό να μη βρει αποτέλεσμα, π.χ. xyzxyz) και ένα κλικ σε πρόταση. Πρέπει να δεις search, search_no_results, select_content με search_term.
  2. Αν βλέπεις ekpa_search αντί για search, δες την παράγραφο για το dataLayer παραπάνω.
  3. Μετά από 24–48 ώρες: Explore → Blank, διάσταση SF Search term, μέτρηση Event count, φίλτρο Event name = search_no_results. Πρέπει να εμφανιστεί λίστα όρων.

Testing και production: το testing (Railway) στέλνει στο ίδιο property. Για διακριτά δεδομένα φιλτράρισε με Hostname ή Page location, ή χρησιμοποίησε Data filter «Developer/Test traffic» και Internal traffic rules για τα δικά σας IP.

4. Αναφορές που χρειάζονται

ΑναφοράΠώςΧρήση

Προαιρετικά: μετατροπή του κουμπιού «Κάνε Αίτηση» (links προς /apply/…) σε key event στο GA4. Έτσι μπορεί να μετρηθεί ποιες αναζητήσεις καταλήγουν σε αίτηση. Δεν το στέλνει το widget: θέλει δικό του event/trigger στο GTM του site.
